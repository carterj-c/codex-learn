# Curricula

This directory intentionally contains no example curriculum. After the learner approves a `$curriculum-designer` draft, it creates `curricula/<subject>/` with the subject policy, map, learner notes, progress evidence, and optional source library.

`learner-notes.md` stores subject preferences, reported struggles, off-map needs, and route decisions. `progress.md` stores observed evidence. The active teacher may update both and make learner-requested route, teaching-modifier, or progression changes during teaching; outcome, scope, and safety changes require explicit confirmation.

Keep personal progress and course materials in a private repository.
