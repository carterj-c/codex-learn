# ML mathematics sources

Place course materials, selected textbooks, lecture slides, handouts, assignment rubrics, and source links for this curriculum in this folder. Keep personal or copyrighted material in a private clone rather than the public upstream repository.

Use `$curriculum-sources` to catalog additions in `catalog.md`. Set `design-brief.md` when you want a curriculum to follow a course outline, selected chapters, or a specific reference policy. The teacher and researcher read the catalog first, then open only the relevant source for a lesson or curriculum-design decision.
