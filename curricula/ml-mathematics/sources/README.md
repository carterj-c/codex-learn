# ML mathematics sources

Place course materials, selected textbooks, lecture slides, handouts, assignment rubrics, and source links for this curriculum in this folder. Keep personal or copyrighted material in a private clone rather than the public upstream repository.

Use `$curriculum-sources` to catalog additions in `catalog.md` and create their compact structural maps in `index.md`. Tell `$curriculum-designer` directly if it should follow a course outline, cover selected chapters, or use a specific reference policy. The teacher and researcher use the catalog and index to find relevant material, then open the original source for a lesson or curriculum-design decision.
